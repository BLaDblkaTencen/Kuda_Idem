# Куда идём?

Telegram Mini App: компания друзей за пару минут выбирает, куда пойти в Севастополе.
Организатор выбирает день и время и отправляет приглашение в чат, друзья отвечают на 4 коротких вопроса,
приложение предлагает 3 места, компания голосует, бот присылает каждому карточку с местом и временем.

Опубликовано: `https://kuda-idem.kuda-idem-sev.workers.dev` (Cloudflare Workers + Neon), см. [DEPLOY.md](DEPLOY.md).

Что есть:
- `apps/server` — API на Hono, база данных, алгоритм подбора, вход через Telegram, бот;
- `apps/web` — экраны Mini App (React + Vite): создание вылазки, анкета, сбор ответов, голосование, итог;
- `data/places-sevastopol.csv` — реальные места Севастополя (собраны по 2ГИС и сайтам заведений).

Один и тот же код сервера работает в двух средах:
- **на вашем компьютере** — Node.js, встроенная база PGlite, бот опрашивает Telegram (`npm run dev`);
- **в продакшне** — Cloudflare Workers, база Neon, бот на вебхуке (`npm run cf:deploy`).

## Что нужно на компьютере

- Node.js 24+
- Docker — не обязателен. По умолчанию база работает встроенно (PGlite — PostgreSQL внутри Node.js),
  данные лежат в папке `.data/`.

## Первый запуск

```bash
npm install
cp .env.example .env      # в Windows: copy .env.example .env
npm run dev               # API на http://localhost:3000
```

При запуске сервер сам создаёт таблицы и загружает места из `data/places-sevastopol.csv`.
Проверка: откройте http://localhost:3000/api/health — должно прийти `{"ok":true,...}`.

Во втором терминале запустите экраны:

```bash
npm run dev:web           # Mini App на http://localhost:5173
```

В браузере сверху есть панель «Разработка · вы: Маша / Петя / Дима» — переключайте пользователя,
чтобы пройти сценарий за всю компанию. Внутри Telegram этой панели нет, пользователь берётся из Telegram.

**Вымышленные тестовые места** (18 штук) нужны только для экспериментов: задайте в `.env`
`SEED_TEST_PLACES=true` — сервер загрузит их при запуске и будет предлагать вместе с реальными.
При `false` они скрыты.

**Вариант с Docker:** `npm run db:up`, затем в `.env` переключите `DATABASE_URL` на строку `postgres://...`
(она есть в `.env.example`). Встроенную базу PGlite может открыть только один процесс.

## Места

Единственный источник мест — таблица [data/places-sevastopol.csv](data/places-sevastopol.csv)
(разделитель «;», UTF-8). Чтобы добавить или поправить место:

1. Отредактируйте таблицу (в Excel — сохранять как «CSV UTF-8, разделитель точка с запятой»).
2. `npm run places:build` — проверит каждую строку и пересоберёт `apps/server/src/db/places.generated.ts`.
   Ошибка покажет номер строки и колонку.
3. `npm run cf:deploy` — сервер сам приведёт базу к таблице: новые места добавит, изменённые обновит,
   убранные скроет (места сопоставляются по колонке `источник_2гис`, её не меняйте).

Колонки: `тип` — категория для подбора, `вид` — что видит пользователь («кинотеатр», «пиццерия»),
`часы` — например `Пн-Пт 08:00-21:00 / Сб-Вс 09:00-21:00`. Допустимые значения типов, районов,
настроений и особенностей — в `apps/server/src/domain/constants.ts`.

## Команды

| Команда | Что делает |
| --- | --- |
| `npm run dev` | API с автоперезапуском при изменении кода |
| `npm run dev:web` | Экраны Mini App |
| `npm run telegram` | Туннель + API + бот + экраны для проверки в Telegram с компьютера |
| `npm test` | Тесты: подбор, часы работы, таблица мест, подпись Telegram, карточка итога, форматирование |
| `npm run smoke` | Весь сценарий вылазки через API за трёх тестовых пользователей (сервер должен быть запущен) |
| `npm run typecheck` | Проверка типов сервера (экраны проверяются при сборке) |
| `npm run places:build` | Таблица мест → код (после каждой правки CSV) |
| `npm run db:generate` | Создать миграцию после изменения `apps/server/src/db/schema.ts` |
| `npm run db:migrate` | Применить миграции (сервер делает это и сам при запуске) |
| `npm run db:seed` | Перезагрузить вымышленные тестовые места (реальные не трогает) |
| `npm run db:up` / `db:down` | Запустить / остановить базу в Docker |
| `npm run cf:dev` | Worker локально в среде Cloudflare (нужен `--var DATABASE_URL:...` или файл `.dev.vars`) |
| `npm run cf:deploy` | Тесты → сборка экранов → публикация на Cloudflare |

```

apps/server/src/
  domain/constants.ts     справочники: настроения, бюджеты, районы, типы, ограничения
  domain/places-csv.ts    разбор и проверка таблицы мест (+ тесты)
  domain/hours.ts         разбор часов работы «Пн-Пт 08:00-21:00» (+ тесты)
  domain/place-name.ts    «Кинотеатр «Победа»», «Идём в пиццерию «Челентано»» (+ тесты)
  domain/result-card.ts   текст карточки итога, которую присылает бот (+ тесты)
  domain/format.ts        дата встречи по времени Севастополя, ссылка на Яндекс Карты
  matching/match.ts       алгоритм подбора 3 мест (+ тесты)
  auth/telegram.ts        проверка подписи initData от Telegram (+ тесты)
  db/schema.ts            таблицы: места, пользователи, вылазки, ответы, варианты, голоса, события
  db/places.generated.ts  места из CSV в виде кода (npm run places:build)
  db/setup.ts             синхронизация мест с таблицей при запуске
  db/seed-places.ts       вымышленные тестовые места
  db/node.ts              подключение для Node.js: PGlite или PostgreSQL, миграции из файлов
  db/worker.ts            подключение для Cloudflare: Neon по HTTP, встроенные миграции
  routes/trips.ts         API вылазки: создать, анкета, подбор, голосование, итог, «поделиться», рассылка карточек
  routes/places.ts        каталог мест
  bot.ts                  бот: /start, опрос или вебхук, сообщения в чат и в личку
  analytics.ts            запись продуктовых событий для метрик
  app.ts                  приложение API (общее для обеих сред)
  index.ts                точка входа Node.js
  worker.ts               точка входа Cloudflare Workers

apps/web/src/
  screens/CreateTrip.tsx  день и время (своё время — полями «часы : минуты»), превью приглашения
  screens/Survey.tsx      анкета: бюджет, настроение, район, ограничения
  screens/Trip.tsx        сбор ответов → голосование (с ничьей) → итог и маршрут
  share.ts                «отправить в чат»: приглашение и итог
  telegram.ts             тема, кнопка «назад», вибрация, разрешение писать в личку
  api.ts                  запросы к серверу и тестовые пользователи для разработки
  ui.tsx                  общие элементы: кнопки, аватарки, защита от двойного нажатия
```

**Подбор.** Отсеиваются закрытые к началу встречи (место должно работать ещё час), не по сезону,
дороже самого маленького бюджета более чем на 20%, не вмещающие компанию и не подходящие под ограничения.
Если не осталось ничего, условия ослабляются по очереди: бюджет → размер компании → ограничения.
Правило «мне нет 18» не ослабляется никогда. Затем места ранжируются по настроению и району,
место, которое совсем не подходит кому-то одному, опускается вниз, и в выдаче не больше двух мест одного типа.

**«Отправить в чат»:** в Telegram с подключённым ботом — нативное окно выбора чата (`shareMessage`),
без бота — ссылка `t.me/share`, в браузере — системное «Поделиться» или копирование текста.

**Карточка итога:** когда организатор завершает голосование, бот присылает в личку организатору и всем,
кто ответил или голосовал, карточку места (вид, время, адрес, чек, часы, кнопки «Маршрут» и «Сайт»).
Писать в личку бот может только тем, кто это разрешил: запустил бота или согласился после анкеты.

Экран вылазки спрашивает сервер о чужих изменениях раз в 10 секунд; свои действия обновляют экран сразу.

### API

Все запросы, кроме `/api/health`, `/api/dictionaries` и `/api/places`, требуют входа:
заголовок `Authorization: tma <initData>` из Telegram Mini App.

| Метод | Путь | Кто | Что делает |
| --- | --- | --- | --- |
| GET | `/api/dictionaries` | все | Подписи для анкеты |
| POST | `/api/trips` | организатор | Создать вылазку `{ startsAt }` |
| GET | `/api/trips/:id` | все | Экран вылазки: участники, варианты, кто за что голосовал |
| PUT | `/api/trips/:id/answer` | участник | Анкета `{ budget, moods, districts, constraints }` (`districts: []` — любой район) |
| POST | `/api/trips/:id/suggest` | организатор | Подобрать 3 места (повторно — «другие варианты») |
| POST | `/api/trips/:id/vote` | участник | Голос `{ placeId }` |
| POST | `/api/trips/:id/finish` | организатор | Завершить голосование (при ничьей — `{ placeId }`), разослать карточки |
| POST | `/api/trips/:id/share/invite` | все | Приглашение для отправки в чат |
| POST | `/api/trips/:id/share/result` | все | Итог для отправки в чат |
| GET | `/api/places` | все | Каталог мест |

Повторные «Подобрать места» и «Завершить» при двойном нажатии не ломают вылазку и не рассылают карточки дважды.

### Разработка без Telegram

Пока `DEV_AUTH=true` (только при `NODE_ENV=development` и только для запросов с localhost),
вместо initData можно передать заголовки `X-Dev-User-Id: 1` и `X-Dev-User-Name: Маша`.

## Запуск в Telegram с вашего компьютера

Telegram открывает Mini App только по HTTPS, поэтому локальное приложение выставляется наружу
через туннель [localhost.run](https://localhost.run) (работает через `ssh`, ставить ничего не нужно).

Используйте здесь **отдельного бота для разработки**: опубликованный бот работает на вебхуке,
и локальный запуск с его токеном откажется стартовать, чтобы его не сломать.

**Один раз:**
1. В Telegram откройте @BotFather → `/newbot` → придумайте имя и username (должен оканчиваться на `bot`).
2. Скопируйте токен в `.env` → `BOT_TOKEN=...`. Токен — секрет: не пересылайте его и не коммитьте `.env`.

**Каждый запуск:**
1. `npm run telegram` — откроет туннель, запустит API, бота и экраны и напечатает адрес `https://….lhr.life`.
2. Если адрес изменился: @BotFather → `/mybots` → ваш бот → Bot Settings → Configure Mini App →
   вставьте адрес. Это нужно для ссылок-приглашений вида `t.me/<бот>?startapp=<id>`.
3. Откройте чат с ботом → `/start` или кнопка «Куда идём?» слева от поля ввода (её бот обновляет сам).

В режиме `npm run telegram` вход для разработки (`X-Dev-User-Id`) выключен — войти можно только как
настоящий пользователь Telegram. Остановить — `Ctrl+C`. Адрес localhost.run временный и меняется при перезапуске.

## Что ещё не решено

- Мест для настроения «на воздухе» и бюджета «бесплатно» пока нет — нужно добавить парки, пляжи, смотровые.
- Районы Севастополя и их соседство — черновик в `domain/constants.ts`, уточнить с тестерами.
- 152-ФЗ (хранение данных в РФ) и политика обработки персональных данных до публичного запуска.
- Пауза опроса, если экран вылазки долго открыт без действий (обсуждено, не сделано).
